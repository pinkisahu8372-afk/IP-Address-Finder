# IP-Address-Finder
A Python based project that finds IP address information using an online API and used to find IP address details like city, country and ISP.
*Features 
1.Find your public IP address.
2.Search details of a specific IP address.
3.Display city and region.
4.Display country.
5.Show latitude and longitude.
6.Identify Internet Service Provider(ISP).
*Technologies Used 
Python 
Requests Library
IP API
*Installation
Install the required library:
pip install requests 
*How to Run 
python project1.py
